Network layer - There is 7 layer
1. Physical
2. Data link  
3. Network 
4. Transport
5. Session
6. Presentation 
7. Application 

NLB - Network Load Balancer
    - It work on layer 4 i.e., transport layer 
    - it use TCP & UDP or TLS traffic
    - Mostly used in banking domain
    - Routing based on IP & Port
    - There is static IP
    - performance is fast

	VS 

ALB - Application Load Balancer 
    - It work on layer 7 i.e., application layer
    - it use HTTP/HTTPS protocol 
    - Routing based on path, hostname, headers
    - No static IP 
    - Performance very high
