# Ansible - Create multiple users in loop

---

- name: Create multiple Pathnex Users
  hosts: all
  become: yes

  vars:
    users:	
	- dev1
	- dev2
	- dev3

  tasks:
	- Create users
	user:
	   name: "{{ item }}"
	   state: present
	loop: "{{ users }}"

# Jenkins pipeline - Simulated deployment
You will learn how to **simulate deployment to different environments**.

pipeline {
	agent any 
	parameters {
	    choice(name: 'ENVIRONMENT', choice: ['dev','stag', 'prod'], description: 'deployment Environment')
	}
	envrionment {
	     INSTITUTE_NAME = "Pathnex"   
	}
	stages {
	   stage('Deploy') {
		steps {
		   sh 'echo "Deployment $INSTITUTE_NAME application to $ENVIRONMENT"'
		}
	  }
     }

}



## GitLab CI - Deployment Simulation
You will learn how to **simulate deployment in GitLab CI using environment variable**.

stages:
   - deploy

variables:
  INSTITUTE_NAME: "Pathnex"
  ENVIRONMENT: "staging"


deploy:
   stage: deploy
   image: alpine:latest
   script:
	- echo "Deploying $INSTITUTE_NAME application to $ENVIRONMENT"
